# Claude Project Instructions

Read first:

@docs/AI_WORKFLOW.md

Before implementing any task:

1. Inspect the relevant existing code.
2. Understand the current Nuxt architecture.
3. Identify affected client/server boundaries.
4. Produce a short implementation plan.
5. Implement the smallest robust change.
6. Run relevant project verification commands.
7. Inspect git diff.
8. Do not commit or push.

Pay particular attention to:

- Nuxt SSR
- hydration
- TypeScript
- runtimeConfig
- server/api
- composables
- state management
- authentication and authorization
- performance
- accessibility

Do not introduce new dependencies without explaining why.
